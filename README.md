This project implements a simulated Smart Home Control System using ROS2, focusing on key home automation features such as lighting control, temperature regulation, and a basic security system. The system leverages ROS2 topics, services, and actions for communication between nodes. All sensor data is simulated, and detailed console output is provided during runtime to illustrate the system’s behavior, making it easy to understand and debug.

Core Features:
Lighting Control: Automatic brightness adjustment and manual user control.

Temperature Control: Simulated temperature readings and climate control.

Security System: Motion detection and simulated alarm system with arm/disarm functionality.

Nodes:
light_control_node: Manages light states and control.

temperature_control_node: Regulates simulated temperature.

security_node: Monitors sensors and triggers alarms.

user_interface_node: Provides a basic command-line or GUI interface.

ROS2 Communication:
Topics, Services, and Actions used for inter-node communication.

Real-time console output for debugging and system status tracking.

The project includes a well-documented codebase and a report detailing the architecture, communication mechanisms, and implementation steps.
